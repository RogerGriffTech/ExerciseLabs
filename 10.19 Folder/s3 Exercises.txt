Section A: Basics
1. What type of storage does Amazon S3 provide: Block, File, or Object?
    Object

2. What is the minimum number of S3 buckets you can create in AWS?
    You don't have to make any S3 buckets if you want to use something else, but if you want to use S3 specifically, you must create at least 1.

3. Write the CLI command to create a bucket named de-course-bucket.
    aws s3api create-bucket --bucket de-course-bucket --region us-east-1

4.
How do you upload a file named data.csv into an S3 bucket using CLI?
    aws s3 cp <path to your data.csv file> <key for your s3 bucket> --storage-class <whatever storage level you want>

5.
What’s the difference between an object key and an object URL ?
    The object key is how AWS identifies your object, the object URL is the web address used to access the object.

What’s the difference between SSE-S3, SSE-KMS and SSE-C?
    SSE stands for Server Side Encryption, after the - is where the key is. SSE-S3 is S3 managing the keys for you, KMS is a Key Management System and C is a combination of the two.
